# Gun Creator v2

[Русский](README.ru.md) | **English**

A PyQt5 desktop app that generates fictional weapon names and characteristics from a selected weapon class and level.

## Included in this repository

- `main.py` builds the Qt interface; `factors.py` calculates damage, speed, accuracy, and ammunition values.
- `Images/` contains weapon and stat artwork; `adjective/` contains text fragments for generated names.

## Getting started

Install Python and PyQt5 (`pip install PyQt5`), then run `python main.py` from the repository root.

## Notes

The generated weapon data is fictional and intended for a small creative prototype.
