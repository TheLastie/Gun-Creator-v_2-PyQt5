# Gun Creator v2

**Русский** | [English](README.en.md)

Настольное приложение на PyQt5 для генерации вымышленных названий и характеристик оружия по выбранному классу и уровню.

## Что находится в репозитории

- `main.py` создаёт интерфейс Qt; `factors.py` рассчитывает урон, скорость, точность и запас боеприпасов.
- В `Images/` лежат изображения оружия и характеристик, а в `adjective/` — части сгенерированных названий.

## Запуск и настройка

Установите Python и PyQt5 (`pip install PyQt5`), затем запустите `python main.py` из корня репозитория.

## Примечания

Сгенерированные характеристики оружия вымышленные; это небольшой творческий прототип.
